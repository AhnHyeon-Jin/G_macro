# G_macro

트리거 이미지가 화면에 보이면 타깃 이미지를 찾아 우클릭하는 Windows용 매크로.

## 설치 (Windows, Python 3.9+)

```
pip install -r requirements.txt
```

DD 입력(`"input": "dd"`)을 쓰려면 DD 드라이버 DLL을 직접 받아 `dd\dd63330.dll`에 넣습니다 (저장소에는 포함하지 않음).
DD 없이 쓰려면 설정 탭에서 입력 방식을 `sendinput`으로 바꾸면 됩니다.

## 사용 순서 (GUI)

1. `gui.bat` 실행 (DD 입력을 쓰면 **관리자 권한으로 실행**)
2. 화면에 뜬 초록색 **오버레이**를 게임 창에 맞춤 (위쪽 탭 드래그 = 이동, 테두리 드래그 = 크기). 게임은 창 모드로 실행하고 오버레이 안에 둔다
   - 오버레이 안쪽이 검색 범위, 가운데 **+** 가 내 캐릭터 위치. 타깃이 여러 개면 가운데와 가장 가까운 것을 클릭
   - 안쪽은 투명하고 클릭이 그대로 게임에 전달됨. 실행 중에는 고정됨
   - **설정** 탭의 **+ 오버레이 추가**로 최대 3개까지 (1 초록 / 2 파랑 / 3 주황). 게임 창을 여러 개 띄울 때 하나씩 맞춤
   - 규칙은 기본으로 모든 오버레이에 각각 적용되고, 규칙 편집 창의 **적용 오버레이**에서 고를 수 있음
3. **규칙** 탭 → 추가 → 트리거/타깃(/알람, 선택) 이미지 옆 **화면 캡처** (3초 후 캡처, 영역 드래그 후 Enter) → 확인
4. (선택) **알람** 탭 → 추가 → 사망 화면·운영자 메시지 등 **알람 이미지** 등록. 어느 오버레이에서든 보이면 경고음 + 매크로 정지 (규칙보다 먼저 검사, 알림 창의 확인을 누르면 경고음 꺼짐)
5. **설정** 탭에서 입력 방식·단축키 등 조정 → **저장**
6. **▶ 시작** 또는 게임에서 **F8**로 시작, **F12**로 정지

설정을 바꾼 뒤에는 정지했다가 다시 시작해야 적용됩니다.

## 일치 기준 정하기 (점수 테스트)

규칙/알람 편집 창의 **일치 기준** 옆 **점수 테스트** 버튼 (또는 `tune.bat`으로 따로 실행).

1. 위쪽에서 템플릿(트리거/타깃/알람 이미지) 선택
2. **화면 캡처 ▾** (오버레이 영역, `tests\` 폴더에 저장) 또는 **이미지 추가**로 테스트 이미지를 여러 장 넣기
3. 이미지마다 더블클릭으로 정답 표시: **있음**(템플릿이 화면에 있음) / **없음**
4. 아래에 나오는 **추천 기준** 확인 → **추천값으로** → **기준 적용**

슬라이더를 움직이면 그 기준에서 잡히는 위치가 초록 박스로, 기준 미달이면 가장 비슷한 위치가 빨간 박스로 표시됩니다.
매크로와 같은 방식(흑백 + TM_CCOEFF_NORMED)으로 계산하므로 점수가 그대로 맞습니다.

## 사용 순서 (콘솔)

1. `capture.bat` 실행 → 이름에 `trigger` 입력 → 3초 안에 게임 화면 띄우기 → 영역 드래그 후 Enter
2. 같은 방법으로 `target` 이미지 저장
3. `run.bat` 실행 → 게임에서 **F8**로 시작, **F12**로 정지 (다시 F8로 재시작)

## config.json

GUI에서 저장하면 이 파일이 갱신됩니다. 직접 편집해도 됩니다.

| 키 | 설명 |
|---|---|
| `monitor` | 검색할 모니터 번호 (1 = 주 모니터) |
| `regions` | 검색 영역 목록 `[[left, top, width, height], ...]` (GUI 오버레이 위치, 최대 3개). 각 영역의 가운데가 내 캐릭터 위치. 비우면 모니터 전체 |
| `overlay` | GUI에서 오버레이를 표시할지 |
| `interval` | 화면 검사 주기(초) |
| `cooldown` | 한 규칙이 우클릭한 뒤 다시 동작하기까지 대기(초). 규칙별로 덮어쓸 수 있음 |
| `return_cursor` | 클릭 후 마우스를 원래 위치로 되돌릴지 |
| `input` | 마우스 입력 방식: `"sendinput"`(Windows 기본 API) 또는 `"dd"`(DD 드라이버 DLL, 관리자 권한 필요) |
| `dd_dll` | `input`이 `"dd"`일 때 DLL 경로. 상대경로는 macro.py 기준 (예: `dd/dd63330.dll`), 절대경로도 가능 |
| `start_key` / `stop_key` | 시작 / 정지 단축키 (`f1`~`f12`, 또는 한 글자). 정지해도 프로그램은 켜져 있어 다시 시작 가능 |
| `exit_key` | 프로그램 종료 단축키. `null`이면 콘솔 창을 닫거나 Ctrl+C로 종료 |
| `alarms[]` | `name`, `image`, `threshold`. 어느 검색 영역에서든 보이면 경고음 + 매크로 정지 (콘솔 모드는 F8로 다시 시작) |
| `debug` | `true`면 매 검사마다 일치 점수를 출력 → `threshold` 조정에 사용 |
| `rules[]` | `trigger`, `target`, `threshold`(0~1, 기본 0.85), `offset`(클릭 위치 보정 `[x, y]`), `clicks`(클릭 횟수, 기본 1), `hold`(누르는 시간 범위 `[최소, 최대]`초, 기본 `[0.05, 0.1]`), `gap`(클릭 사이 간격 범위, 기본 `[0.1, 0.2]`), `overlays`(적용할 오버레이 번호 목록, 생략하면 전체). `alarm`(선택: 이미지 경로 목록, 최대 2개. 하나라도 적용 오버레이에 보이면 경고음 + 매크로 전체 정지). 여러 개 가능. 타깃이 여러 개면 검색 영역 가운데와 가장 가까운 것을 클릭 |

## 다른 PC에서 Python 없이 실행

`build.bat` 실행 → 생성된 `dist` 폴더를 통째로 복사.

- `G_macro.exe`: GUI. 실행할 때 관리자 권한을 요청함 (DD 입력용)
- `G_macro_cli.exe`: 콘솔 모드 (`run.bat`과 동일)
- `config.json`, `images\`, `dd\`

## 문제 해결

- **클릭이 게임에 안 먹힘**: 게임이 관리자 권한으로 실행 중이면 매크로도 "관리자 권한으로 실행" 해야 함.
- **이미지를 못 찾음 / 화면이 검게 캡처됨**: 게임을 *전체 화면* 대신 *창 모드* 또는 *테두리 없는 창 모드*로 설정.
- **점수가 애매하게 낮음**: 이미지를 캡처한 해상도·UI 배율과 실행하는 PC의 설정이 같아야 함. 다른 PC라면 그 PC에서 다시 캡처하는 것이 가장 확실.
- **엉뚱한 곳을 클릭**: `threshold`를 올리거나 더 특징적인 부분만 잘라서 다시 캡처.
